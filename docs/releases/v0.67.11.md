# Autolith 0.67.11

## Features

- Serve remote ACP clients with `autolith acp --http` or `autolith acp --websocket`. Each client has independent sessions, with one shared primary operation across clients. Optional bearer-token authentication is available; use a TLS reverse proxy for remote access.

## Fixes

- Package the selected ColorLisp DLL on Windows, validate its x64 PE headers, and check syntax highlighting against the exact packaged library. Exercise packaging under Windows PowerShell 5.1 and PowerShell 7.
- Block new mission work when inference usage is unknown without cancelling already-running children. Account for undispatched requests as zero usage and drain children only for noncancelling budget blocks.
- Exit ACP and recovery quietly with status 130 on Ctrl-C. Preserve failed ACP command status instead of opening recovery, and load the recovery launcher's image-generation dependency.
- Synchronize remote ACP transport shutdown through the updated agentcomms dependency.
- Simplify the boot-screen start prompt.

Update with `(update)`.
