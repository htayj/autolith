# Autolith 0.67.9

## Fixes

- Run scheduled mission wakeups noninteractively so evaluation failures are recorded without stopping queued work at a restart prompt. [#136](https://github.com/lambda-symbolics/autolith/pull/136)
- Resume unrelated asynchronous completions after a mission ends, without spending the retained mission's budget. Deliver only completion events admitted by the current ticket. [#138](https://github.com/lambda-symbolics/autolith/pull/138)
- Protect running shell logs and quota reservations across processes. Reclaim abandoned allocations and manifest staging files after interrupted writes. [#140](https://github.com/lambda-symbolics/autolith/pull/140)

Thanks to Taylor (@htayj) for all three fixes.
