# Autolith 0.67.13

## Fixes

- Recognize durable completion receipts in their owner's storage when pruning tool results. Index receipt lookups to avoid repeated scans of large histories.
- Keep captured reasoning and parallel tool calls together in Chat requests, including blocked calls retained for one response. Cache only the unchanged durable prefix.
- Retain tool schemas when a restricted turn must answer without calling tools.
- Allow parallel tool calls on the public OpenAI route and use the conversation cache key for request routing.
- Build macOS releases on supported runners.

## Improvements

- Put shared inference views before the task to improve prompt-cache reuse, and title inference traces by their task.
- Toggle the session's relax reminder without invalidating the main prompt's cached prefix.
